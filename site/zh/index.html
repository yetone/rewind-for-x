刚被刷掉的推文，随时找回来

X 首页一刷新，看到一半的好帖子就被顶没了。Rewind for X 会记下你看到过的每条推文，就存在你的浏览器里。

添加到 Chrome GitHub

边刷边记

推文露出一半以上就算看过，记下作者、正文、图片、引用推文和链接。广告不记。

一键打开

点 X 悬浮按钮上方的回看按钮、工具栏图标，或按 Alt Shift R。最新的在最上面，按看到的时间分组。

新标签页打开

点推文在新标签页里看原帖，首页不会再刷新一次。

什么都能搜

按作者、@用户名、正文里的任意词，甚至图片里的文字来找。

按类型筛选

只看带图片、视频、引用或转帖的推文。

和 X 一个样

跟随 X 的浅色、暗蓝和纯黑主题，窄窗口里也合身。

记录只留在你的设备上

推文保存在浏览器的扩展本地存储里。没有账号，没有统计，不上传任何东西。

最多保留最近 3000 条，点两下即可全部清空。

查看隐私政策

安装

  1. 下载扩展并解压。
  2. 打开 chrome://extensions，打开右上角的开发者模式。
  3. 点加载已解压的扩展程序，选择解压出来的文件夹。
  4. 打开或刷新 x.com/home。
Rewind for X 是独立开发的项目，与 X Corp. 无关。
